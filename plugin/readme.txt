Companion functionality for the WordPress Project Boilerplate hybrid theme.

== Description ==

This template plugin provides the project container, block registration and REST API structure. Customize its name, description, text domain and code before shipping a client project. The theme depends on this plugin for shared functionality.

== Installation ==

Install the companion plugin ZIP and activate it before activating the theme. The release ZIP includes production Composer dependencies.
